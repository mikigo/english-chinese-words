    • actual state （现实状态，实际状况）

    • actual use （实际使用）

    • actual demand （实际需求）

    • actual value （实际价值；实际指标）

    • actual measurement （实测；实物测量）

    • actual life （实际寿命；有效寿命）

    • your actual （[口语]原产的；真正的）

    • actual cost （实际成本；额外费用）

    • actual need （实际需要）

    • actual practice （实际应用）

    • actual result （实际结果）

    • actual test （实际试验）

    • actual number （n. 实数，实际数量）

    • actual size （实际尺寸；实际大小）
