    • search algorithm （搜算法，搜索算法）

    • job search （寻找工作；职位搜索；工作搜寻）

    • information search （信息搜索）

    • search function （检索功能；搜索函数）

    • literature search （文献检索；文献研究）

    • search out （vi. 寻找到；查出）

    • in search for （寻求；寻找）

    • search after （探索；寻找）

    • advanced search （高级搜索）
