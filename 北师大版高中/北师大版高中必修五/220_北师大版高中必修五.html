    🤩短语

    • dynamic characteristic （动态特性；负载特性曲线）

    • dynamic system （动力系统）

    • dynamic programming （动态规划；动态程序设计）

    • dynamic load （动载荷，动力载荷）

    • dynamic behavior （动态行为；动态特性；能动行为）

    • dynamic balance （动态平衡，动平衡）

    • dynamic range （动态范围）
