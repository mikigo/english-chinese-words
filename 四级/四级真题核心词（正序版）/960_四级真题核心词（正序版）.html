    #960. agent

    'eidʒənt 代理商

    🤩短语

    • travel agent （旅行社；旅行代理人，旅行代办人）

    • active agent （活性剂）

    • general agent （总代理人）

    • foaming agent （发泡剂；泡沫剂）
