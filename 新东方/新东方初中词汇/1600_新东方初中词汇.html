    #1600. heel

    脚后跟， 踵； 后跟

    🤩短语

    • achilles heel （致命要害；薄弱环节）

    • high heel （高跟鞋）

    • achilles' heel （唯一的致命的弱点）

    • at heel （adv. 接踵；尾随）

    • under the heel of （被…践踏；在…掌握中）

    • the heel of achilles （唯一的致命弱点）

    • wedge heel （坡跟鞋；楔形跟）

    • high heel shoes （高跟鞋）

    • stiletto heel （n. （女式高跟皮鞋的）细鞋跟）

    🎤例句
    • black boots with high heels （有高跟的黑靴子）
    🤔同义词
    • careen （倾侧）

    #1601. disturb

    弄乱， 打乱； 打扰； 使烦恼

    🎤例句

    • let, violate （打扰；妨碍；使不安；弄乱；使恼怒）

    • if so （如果是这样的话；要是这样）

    • or so （大约，左右）

    • so long as （adv. 只要）

    • even so （虽然如此，即使如此）

    • so far as （只要；就…而言；在…范围内）

    • just so （正是如此）

    • more so （更是这样， 尤其如此）

    • so so （马马虎虎；勉强过得去）
