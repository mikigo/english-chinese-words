# Ogden's Basic English 850

Ogden's Basic English 由 Charles Kay Ogden 于 1930 年提出，
旨在用最少的词汇表达最广泛的意思。这 850 个核心词汇分为五大类。

## 分类总览

| [通用事物（General Things）](general-things.md) | General Things | 400 |
| [可图示事物（Picturable）](picturable.md) | Picturable | 200 |
| [通用性质（Qualities General）](qualities-general.md) | Qualities General | 100 |
| [反义词（Opposites）](opposites.md) | Opposites | 50 |
