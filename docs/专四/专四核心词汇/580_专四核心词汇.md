# 580_专四核心词汇

## 580. hustle

**催促；猛推；强夺**

**推；奔忙；拥挤喧嚷**

:::tip{title=🤩短语}

- hustle and bustle （熙熙攘攘，忙碌）

:::

:::note{title=🎤例句}

- The guards hustled Harry out of the car. （卫兵们把哈里从车子里拉了出来。）

:::

:::warning{title=🤔同义词}

- crowd, urge （催促；猛推；强夺）

- make haste, jump to it （赶紧；硬挤过去；拼命挣钱）

- push, jundy （推；奔忙；拥挤喧嚷）

:::
