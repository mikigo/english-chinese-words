# 220_专四核心词汇

## 220. firsthand

`'fə:st'hænd`  **直接的；直接采购的；直接得来的**

`'fə:st'hænd`  **直接地**

:::tip{title=🤩短语}

- firsthand information （第一手资料）

:::

- immediate, direct, right （直接的；直接采购的；直接得来的）

- directly, straight, immediately, fair （直接地）

:::
