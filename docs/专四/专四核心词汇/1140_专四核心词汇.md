`trɔ:l`  **用拖网捕鱼**

- The new analysis used catch data as well as stock assessments, scientific trawl surveys, small-scale fishery data and modelling results. （这项新研究利用捕捞量、种群评估、科学的拖网调查、小规模渔业数据以及模型进行分析。）

:::

:::warning{title=🤔同义词}
