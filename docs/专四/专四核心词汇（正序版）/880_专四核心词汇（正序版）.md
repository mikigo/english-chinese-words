# 880_专四核心词汇（正序版）

## 880. defy

`di'fai, 'di:-`  **藐视；公然反抗；挑衅；使落空**

`di'fai, 'di:-`  **挑战；对抗**

:::note{title=🎤例句}

- This was the first (and last) time that I dared to defy my mother. （这是我第一次（也是最后一次）胆敢违抗我母亲。）

:::

:::warning{title=🤔同义词}

- spurn at, sneeze at （藐视；公然反抗；挑衅；使落空）

- challenge, dare, war, confrontation （挑战；对抗）

:::
