# 1920_专四核心词汇（正序版）

## 1920. intricate

`'intrikət`  **复杂的；错综的，缠结的**

:::note{title=🎤例句}

- intricate patterns （繁复的图案）

:::

:::warning{title=🤔同义词}

- complicated, sophisticated, involved, detailed （复杂的；错综的，缠结的）

:::


## 1921. introduce

`,intrə'dju:s`  **介绍；引进；提出；采用**

:::tip{title=🤩短语}

- introduce oneself （自我介绍）

- introduce myself （自我介绍）

- introduce yourself （自我介绍；介绍你自己）

:::
