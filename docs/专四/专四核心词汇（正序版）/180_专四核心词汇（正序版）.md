# 180_专四核心词汇（正序版）

## 180. apt

`æpt`  **恰当的；有…倾向的；灵敏的**

`æpt`  **(Apt)人名；(法、波、英)阿普特**

:::note{title=🎤例句}

- ‘Love at first sight’ is a very apt description of how he felt when he saw her. （用“一见钟情”来形容他见到她时的感觉再恰当不过。）

:::

:::warning{title=🤔同义词}

- sensitive, correct, quick, prone, liable （恰当的；有…倾向的；灵敏的）

:::
