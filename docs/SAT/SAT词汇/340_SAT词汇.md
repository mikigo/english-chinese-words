## 340. autonomous

`ɔ:'tɔnəməs`  **自治的；自主的；自发的**

:::tip{title=🤩短语}

- autonomous region （自治区）

- autonomous county （自治县）

- autonomous prefecture （自治州）

- autonomous system （自治系统；独立系统）

- autonomous operation （独立作战；自仲作）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- initiative, spontaneous （[生物][植]自治的；自主的；自发的）

:::
