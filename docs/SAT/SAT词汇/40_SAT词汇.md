# 40_SAT词汇

## 40. constructive

`kən'strʌktiv`  **建设性的；推定的；构造上的；有助益的**

:::tip{title=🤩短语}

- constructive total loss （[经]推定全损）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- putative （建设性的；推定的；构造上的；有助益的）

:::
