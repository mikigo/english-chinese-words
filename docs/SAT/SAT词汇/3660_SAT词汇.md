# 3660_SAT词汇

## 3660. abject

**卑鄙的；可怜的；不幸的；（境况）凄惨的，绝望的**

:::note{title=🎤例句}

- an abject apology （低声下气的道歉）

:::

:::warning{title=🤔同义词}

- poor, base, mean, evil, dirty （卑鄙的；可怜的；不幸的）

:::
