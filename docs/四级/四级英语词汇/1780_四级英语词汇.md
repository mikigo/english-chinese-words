## 1780. anywhere

`'enihwεə`  **在什么地方**

:::tip{title=🤩短语}

- or anywhere （或是什么别的地方，或其他某地）

- get anywhere （有点成就）

- anywhere near （[口]接近于；全然；差不多）

- anywhere is （无处不在；任何地方都是如此）

- anywhere you go （到处）

- if anywhere （如果有什么地方的话，如果在哪儿能…的话）

:::

:::note{title=🎤例句}

- I haven't got anywhere to live. （我没有任何地方住。）

:::

:::warning{title=🤔同义词}

- whithersoever （在任何地方；无论何处）

- nowhere （任何地方）

:::
