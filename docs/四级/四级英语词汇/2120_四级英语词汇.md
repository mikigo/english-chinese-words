## 2120. nobody

`'nəubədi, -bɔdi`  **谁也不；无人**

:::tip{title=🤩短语}

- nobody else （没有其他人）

- nobody home （无人在家；心不在焉）

- nobody can stop （无人能阻止（歌词））

- a mere nobody （微不足道的人）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- small potatoes, worm （无名小卒；小人物）

:::

- generalized anxiety disorder （广泛性焦虑，广泛性焦虑障碍）
