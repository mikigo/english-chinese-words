# 440_四级真题核心词（正序版）

## 440. inevitable

`in'evitəbl`  **不可避免的**

:::note{title=🎤例句}

- A further escalation of the crisis now seems inevitable. （危机的进一步升级现在看来已不可避免。）

:::

:::warning{title=🤔同义词}

:::
