:::tip{title=🤩短语}

- tour group （旅行团；旅游团队）

- city tour （市区观光，城市观光；市内旅游）

- study tour （考察团）

- package tour （包办旅行（路线、地点、时间和费用等均作统一规定和安排的旅游））

- sightseeing tour （观光旅游）

- tour operator （旅行社；包价旅游承办商）

- concert tour （n. 演奏旅行）

- grand tour （（从前英国贵族子女的）遍游欧洲大陆的教育旅行）

- tour of duty （任期；服役期；值班）

:::note{title=🎤例句}
