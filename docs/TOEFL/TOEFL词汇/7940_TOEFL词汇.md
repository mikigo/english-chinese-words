## 7940. gamble

`'ɡæmbl`  **(打)赌；投机，冒险**

:::tip{title=🤩短语}

- gamble away （赌光）

:::

:::

:::warning{title=🤔同义词}

- game, venture, lay （赌博；孤注一掷；投机；打赌）

- put all one's eggs in one basket, shoot the works （赌博；孤注一掷；冒险假设）

- risk, throw, gaming, venture, adventure （赌博；冒险；打赌）

:::
