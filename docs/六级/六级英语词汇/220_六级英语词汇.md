# 220_六级英语词汇

## 220. liable

`'laiəbl`  **有（法律）责任的**

:::tip{title=🤩短语}

- liable for （adj. 对……有责任）

- liable to tax （应纳税；应课税）

:::

:::note{title=🎤例句}

- The airline's insurer is liable for damages to the victims' families. （航空公司投保的保险公司为遇难者家庭的损失负法律责任。）

:::

:::warning{title=🤔同义词}

- responsible, bound, accountable, prone （有责任的，有义务的；应受罚的；有…倾向的；易…的）

:::
