# 440_六级英语词汇

## 440. extinguish

`ik'stiŋɡwiʃ`  **熄灭，扑灭；消灭**

:::note{title=🎤例句}

- Please extinguish all cigarettes. （请把香烟都熄灭了。）

- Firemen were called to extinguish the blaze. （有人打电话叫消防队员来扑灭大火。）

:::

:::warning{title=🤔同义词}

- silence, go out （熄灭；压制；偿清）

:::
