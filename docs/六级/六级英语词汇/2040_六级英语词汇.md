# 2040_六级英语词汇

## 2040. retort

`ri'tɔ:t`  **反击；反驳**

:::tip{title=🤩短语}

- retort pouch （蒸煮袋；杀菌袋）

:::

:::note{title=🎤例句}

- ‘It’s all your fault!’ he retorted. （“那都是你的错！”他反驳道。）

:::

:::warning{title=🤔同义词}

- contradiction, oppugnation （反驳，顶嘴；曲颈瓶）

- refute, disprove （反驳，反击）

- talk back, answer sb. back （反驳，回嘴）

:::
