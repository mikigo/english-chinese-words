## 1520. split

`split`  **分裂，分化，派系**

:::tip{title=🤩短语}

- split up （分裂，分离）

- split second （一刹那；极快的）

- split hairs （斤斤计较，在小事上争论不休；作无益的、琐碎的分析）

- split off （分离；分裂）

- split type （拼合式）

- split share （分割股）

- split the cost （分担成本）

- banana split （香蕉圣代（剖开香蕉夹以冰淇淋等）；香蕉半剖条）
