:::tip{title=🤩短语}

:::

## 948. incompatibility

`'inkəm,pætə'biləti`  **不兼容**

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- variance, disparity （[免疫][数]不相容；不协调；不一致）

:::
