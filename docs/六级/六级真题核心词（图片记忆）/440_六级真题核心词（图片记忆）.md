# 440_六级真题核心词（图片记忆）

## 440. confer

`kən'fə:`  **授予**

:::tip{title=🤩短语}

- confer with （协商；交换意见）

- confer on （vt. 授给（授予））

:::

:::note{title=🎤例句}

- The constitution also confers large powers on Brazil's 25 constituent states. （宪法还授予巴西25个成员州极大的权力。）

:::

:::warning{title=🤔同义词}

- afford, award, allow, grant, deal （授予；给予）

- arrange, treat （协商）

:::
