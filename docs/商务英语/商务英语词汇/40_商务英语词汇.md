## 40. paradox

`'pærədɔks`  **悖论，反论；似非而是的论点；自相矛盾的人或事**

:::note{title=🎤例句}

- It’s a paradox that in such a rich country there can be so much poverty. （在如此富有的国家却有这么多的贫穷现象，真是矛盾。）

:::
