## 1320. landmark

**[航]陆标；地标；界标；里程碑；纪念碑；地界标；划时代的事**

**有重大意义或影响的**

:::

- Placemark, checkpost （[航]陆标，地标；[建]里程碑；[地理][测]地界标；划时代的事）

:::
