## 6740. exotic

`,iɡ'zɔtik`  **异国的；外来的；异国情调的**

:::tip{title=🤩短语}

- exotic dancer （脱衣舞女）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- outside, extraneous （[物]异国的；[语]外来的；异国情调的）

:::
