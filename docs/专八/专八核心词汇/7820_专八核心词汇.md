## 7825. for

**为，为了；因为；给；对于；至于；适合于**

**因为**

:::tip{title=🤩短语}

- for all （尽管；虽然）

- as for （关于，至于）

- up for （打算；在选举中被提名；在法庭受审；被关押）

- for one （举个例说；作为其中一个）

- do for （毁坏；代替；对…有效）

- go for （去找；被认为；主张；拥护；努力获取）

- go in for （参加，从事；追求；赞成）

:::
