# 1340_专八核心词汇

## 1340. futuristic

`,fju:tʃə'ristik`  **未来派的；未来主义的**

:::note{title=🎤例句}

- The futuristic sports stadium is the pride of the city. （这座超现代的体育场是该市的骄傲。）

:::

## 1341. comprise

`kəm'praiz`  **包含；由…组成**

:::tip{title=🤩短语}

:::

:::

:::warning{title=🤔同义词}

- involve, contain （包含；由…组成）

:::
