## 4060. furl

`fə:l`  **叠，卷收；收拢**

`fə:l`  **卷起，折叠；卷起之物**

:::note{title=🎤例句}

- An attempt was made to furl the headsail. （有人试着收起前桅帆。）

- ...a furled umbrella. （...一把收拢的雨伞。）

:::

:::warning{title=🤔同义词}

- tuck （叠，卷收；收拢）

- curl up, roll up （收拢，卷起）

- rolled up, foldover （卷起，折叠；卷起之物）

:::
