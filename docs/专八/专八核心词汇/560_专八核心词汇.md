# 560_专八核心词汇

## 560. hi

`hai`  **嗨！（表示问候或用以唤起注意）**

`hai`  **(Hi)人名；(柬)希**

:::tip{title=🤩短语}

- hi there （嘿，你好(或你们好)）

:::

:::note{title=🎤例句}

- Hi! How are you? （嗨！你好吗？）

- Hi there! I haven’t seen you for ages. （嘿！好久不见。）

:::

:::warning{title=🤔同义词}

- come, heigh （嗨！（表示问候或用以唤起注意））

:::


## 561. sock
