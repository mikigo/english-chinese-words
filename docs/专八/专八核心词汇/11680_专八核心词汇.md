## 11683. predicate

`'predikeit`  **断定为…；使…基于**

`'predikeit`  **谓语，述语**

`'predikeit`  **谓语的；述语的**

:::tip{title=🤩短语}

- (grammatical) predicate （（语法）谓语）

- predicate logic （谓词逻辑）

- predicate verb （谓语动词）

- predicate calculus （谓词演算）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- protest, conclude （断言，断定）

- adnex （谓语，述语）

:::
