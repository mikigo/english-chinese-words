# 8320_专八核心词汇

## 8320. pretext

`'pri:tekst`  **借口；托辞**

`'pri:tekst`  **以…为借口**

:::tip{title=🤩短语}

- on the pretext of （以...为借口）

- find a pretext for （为…找口实）

:::

:::note{title=🎤例句}

- He’ll phone on some pretext or other. （他会以这样或那样的理由打电话的。）

:::

:::warning{title=🤔同义词}

- excuse, blind （借口；托辞）

:::

## 8335. tread

- tread water （踩水）

- tread pattern （胎面花纹）

- wheel tread （车轮踏面；轮距）
