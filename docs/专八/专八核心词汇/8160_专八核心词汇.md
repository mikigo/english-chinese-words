## 8160. imaginary

`i'mædʒinəri`  **虚构的，假想的；想像的；虚数的**

:::tip{title=🤩短语}

- imaginary part （[计]虚部）

- imaginary line （假想线；虚线）

- imaginary number （虚数）

- imaginary circle （虚圆）

:::
