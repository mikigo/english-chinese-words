- at fault （出毛病；感到困惑）

- fault tolerance （容错，故障容差）

- fault current （故障电流；事故电流）

- active fault （活动断裂；活性断层）

- fault system （断层系统）

- fault line （断层线；裂纹线）

- fault rate （n. 故障率；损坏率）

:::note{title=🎤例句}

:::warning{title=🤔同义词}
