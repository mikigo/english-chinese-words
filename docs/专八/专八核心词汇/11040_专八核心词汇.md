- a little while （不久，一会儿）

- all the while （一直；始终）

- quite a while （有一阵子，半天；相当长一段时间）

- a while ago （刚才，方才）

- at whiles （有时；间或；有时常常）

- a while back （一段时间之前，不久之前；前阵子）

- while away （消磨；消磨时间）
