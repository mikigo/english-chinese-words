## 9080. rebuke

`ri'bju:k`  **指责，非难；制止；使相形见绌**

`ri'bju:k`  **非难，指责；谴责，鞭策**

:::tip{title=🤩短语}

- without rebuke （无可指摘的；无可非议的）

:::

:::

:::warning{title=🤔同义词}

:::
