# 2080_专八核心词汇（正序版）

## 2080. congenial

`kən'dʒi:njəl`  **意气相投的；性格相似的；适意的；一致的**

:::note{title=🎤例句}

- Compost provides congenial conditions for roots to develop. （堆肥为根部的生长提供了适宜的条件。）

:::

:::warning{title=🤔同义词}

- united, consistent, corresponding, solid, matching （意气相投的；性格相似的；适意的；一致的）

:::

:::warning{title=🤔同义词}

:::
