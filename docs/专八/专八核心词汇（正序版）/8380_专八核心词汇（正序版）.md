# 8380_专八核心词汇（正序版）

## 8380. prescribe

`pris'kraib`  **规定；开药方**

:::tip{title=🤩短语}

- prescribe for （开处方，开药方）

:::

:::note{title=🎤例句}

- What punishment does the law prescribe for this crime? （法律规定这种罪行应受何处罚？）

:::

:::warning{title=🤔同义词}

- to stipulate, to formulate （规定；开药方）

- define, regulate, state, rule （规定；开处方）

:::
