# 3220_专八核心词汇（正序版）

## 3220. dramatic

**戏剧的；急剧的；引人注目的；激动人心的**

:::note{title=🎤例句}

- A superb goal by Owen earned United a dramatic victory yesterday. （昨天欧文的一个超级入球为联队赢得了激动人心的胜利。）

:::

:::warning{title=🤔同义词}

- attractive, scenic （戏剧的；引人注目的；激动人心的）

:::
