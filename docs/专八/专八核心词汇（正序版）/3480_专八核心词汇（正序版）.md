# 3480_专八核心词汇（正序版）

## 3480. elucidate

`i'lu:si,deit`  **阐明；说明**

:::note{title=🎤例句}

- The full picture has not yet been elucidated. （详细情况还没有解释清楚。）

:::

:::warning{title=🤔同义词}

- say, clarify （阐明；说明）

:::


## 3481. elude

:::warning{title=🤔同义词}

:::

:::warning{title=🤔同义词}

:::

## 3487. embargo
