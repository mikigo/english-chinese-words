# 2980_专八核心词汇（正序版）

## 2980. discern

`di'sə:n, -'zə:n`  **识别；领悟，认识**

:::note{title=🎤例句}

- You need a long series of data to be able to discern such a trend. （你需要一大串数据才能认清这一趋势。）

:::

:::warning{title=🤔同义词}

- recognize, identify （识别；领悟，认识）

- see clearly, tell from （看清楚，辨别）

:::
