## 4140. fetching

`'fetʃiŋ`  **迷人的；动人的；吸引人的**

:::tip{title=🤩短语}

- fetch in （引进，招来）

- fetch up （引起；到达；最终成为）

- fetch and carry （做杂务，打杂）

- fetch out （拿出；引出；使显出）

- fetch information （提取信息）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- attractive, affecting, moving, killing, taking （迷人的；动人的；吸引人的）

:::
