## 11660. utility

`ju:'tiləti`  **实用的；通用的；有多种用途的**

- marginal utility （边际效用）

- utility boiler （电站锅炉，动力锅炉；公用锅炉）

- utility system （实用系统；应用系统；公用系统）

- expected utility （期望效用）
