## 1340. bumper

**丰盛的，丰富的**

**缓冲器，保险杆，减震物**

**装满；为…祝酒**

**干杯**

- bumper sticker （保险杆贴纸；车尾贴）

- bumper car （n. 碰撞用汽车）

:::

:::note{title=🎤例句}

:::
