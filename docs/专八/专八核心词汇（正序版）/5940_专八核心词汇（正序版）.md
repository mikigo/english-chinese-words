# 5940_专八核心词汇（正序版）

## 5940. inherit

`in'herit`  **继承；遗传而得**

:::note{title=🎤例句}

- inherited wealth （继承的财富）

:::

:::warning{title=🤔同义词}

- succeed to, take sth over （继承；遗传而得）

:::

- autosomal dominant inheritance （常染色体显性遗传）

- inheritance law （继承法）

- mendelian inheritance （[生]孟德尔氏遗传）

:::

:::note{title=🎤例句}
