# 80_专八真题高频词

## 80. mediocre

`,mi:di'əukə, 'mi:diəukə`  **普通的；平凡的**

:::note{title=🎤例句}

- I thought the book was pretty mediocre. （我认为这本书非常一般。）

- a mediocre student （能力一般的学生）

:::

:::warning{title=🤔同义词}

- ordinary, general, secondary, middle, average （普通的；平凡的；中等的）

:::
