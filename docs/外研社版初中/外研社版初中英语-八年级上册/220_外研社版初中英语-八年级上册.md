- windy day （有风的日子；刮风的天气）

- windy city （风之城（美国城市芝加哥的别称））

:::

:::note{title=🎤例句}

- It’s too windy for a picnic. （风太大，不适合野餐。）

- a cold, windy day （一个寒冷的大风天）

- a windy hillside （当风的山坡）

:::

:::warning{title=🤔同义词}

- blowy, thrasonical （多风的，有风的；腹胀的；吹牛的）

:::
