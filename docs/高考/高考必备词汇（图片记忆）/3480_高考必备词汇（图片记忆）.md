**这；这个；这里**

**这；本；这个；今**

**这样地；这么**

**(This)人名；(法)蒂斯**

:::note{title=🎤例句}

- The table’s about this high and this wide. （那桌子大约有这么高，这么宽。）

- You need to cut about this much off the end of the pipe. （你要从管子头上切下大约这么多。）

:::

:::warning{title=🤔同义词}

- so much （这样地；这么）

:::
