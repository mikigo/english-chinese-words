## 168. sake

**目的，利益**

:::tip{title=🤩短语}

- for the sake （为了…；为了...的利益）

- for the sake of （为了；为了…的利益）

- for god's sake （看在上帝面上）

- for sake （为了…的缘故）

- for sake of （为了…）

- for heaven's sake （看在上帝的份上）

- without sake （adv. 无缘无故）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- goals, intention, purpose, behalf, objective （目的；利益；理由；日本米酒）

:::
