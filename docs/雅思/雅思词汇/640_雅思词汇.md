## 640. passport

`'pɑ:spɔ:t, 'pæs-`  **护照，保障，手段**

:::tip{title=🤩短语}

- passport number （护照号；护照号码）

- passport control （护照检查处；入境检验；验护照）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- protection, instrument, shift, road, tool （[法]护照，通行证；手段）
