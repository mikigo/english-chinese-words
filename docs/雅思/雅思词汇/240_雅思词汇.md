## 240. proceed

**进行；着手**

:::tip{title=🤩短语}

- proceed with （继续进行）

- proceed from （从...出发）

- proceed against （起诉；控诉；提起诉讼）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- occur, happen, travel, pursue （开始；继续进行；发生；行进）

:::
