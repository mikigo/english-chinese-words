## 81. reckon

`'rekən`  **计算**

:::tip{title=🤩短语}

- reckon with （处理；对付；和…算帐；预料到）

- reckon on （指望；依赖）

- reckon in （把…计算在内）

- reckon up （计算；合计）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- expect, feel, find, cast, make （测算，估计；认为；计算）

- estimate, believe, imagine, cast （估计；计算；猜想，料想）

:::
