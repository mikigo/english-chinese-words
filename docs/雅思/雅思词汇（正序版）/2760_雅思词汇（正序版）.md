# 2760_雅思词汇（正序版）

## 2760. dedicated

`'dedikeitid`  **献身的，一心一意的，热诚的**

:::tip{title=🤩短语}

- dedicated line （专线；专用线路）

- dedicated team （特别小组；专门小组）

- dedicated computer （专用电脑）

- dedicated channel （[计]专用信道）

:::

:::note{title=🎤例句}

- a dedicated and thoughtful teacher （一位富有敬业精神、待人体贴的教师）

:::

:::warning{title=🤔同义词}

- devoted, special （[计]专用的；专注的；献身的）

:::
