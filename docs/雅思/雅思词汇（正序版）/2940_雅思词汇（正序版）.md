- host city （n. 主办城市；举办城市）

- host rock （主岩；母岩；容矿岩）

- host plant （寄主植物）

- host cell （宿主细胞）

- host name （[计]主机名）

- host nation （东道国）

- remote host （[计]远程主机）

- host machine （主机）

- host system （[计]主系统；值统）

- play host to （v. 招待）

- intermediate host （中间宿主）

- host range （宿主范围；寄侄围）

- host address （主机地址）

- host processor （主处理机）
