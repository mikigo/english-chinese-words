# 780_雅思词汇（正序版）

## 780. submerge

`səb'mə:dʒ`  **放于水下；使沉没**

:::note{title=🎤例句}

- Hippos are unable to submerge in the few remaining water holes. （河马无法淹没在仅存的几个水坑里。）

:::

:::warning{title=🤔同义词}

- flood, flow （淹没；把…浸入；沉浸）

- drown out, swallow up （淹没；潜入水中；湮没）

:::
