# 440_考研必考词汇（正序版）

## 440. ingenious

`in'dʒi:njəs`  **机敏的;有独创性的;精致的;精巧制成的**

:::note{title=🎤例句}

- Many fish have ingenious ways of protecting their eggs from predators. （很多鱼都有绝妙的方法来保护它们产的卵不被捕食者吃掉。）

- an ingenious device （精巧的装置）

:::

:::warning{title=🤔同义词}

- prepared, clever （有独创性的；机灵的，精制的；心灵手巧的）

:::
