# 2620_新东方TOEFL词汇

## 2620. henceforth

**从此以后**

:::tip{title=🤩短语}

- from henceforth （[古语]从此 [亦作 henceforward]）

:::

:::note{title=🎤例句}

- multiple sclerosis (henceforth referred to as MS) （多发性硬化（以下称为MS））

:::

:::warning{title=🤔同义词}

- forwards, hereafter （今后；自此以后）

:::

:::warning{title=🤔同义词}
