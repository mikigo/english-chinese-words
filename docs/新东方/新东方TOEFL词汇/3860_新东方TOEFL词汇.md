**敏捷的；及时的，迅速的**

**促进，推动；提示；鼓励**

**提词， 提示**

:::tip{title=🤩短语}

- command prompt （命令提示符）

- prompt attention （从速办理）

- prompt payment （立即付款）

- voice prompt （语音提示，声音提示）

- prompt shipment （即期装船）

- prompt in （对…很迅速）

:::

:::note{title=🎤例句}

- Prompt payment is requested. （请立即付款。）

- a prompt response （迅速的答复）

:::

:::warning{title=🤔同义词}

- rapid, fast, fly, forward, ready （敏捷的，迅速的；立刻的）
