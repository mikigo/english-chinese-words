# 3420_新东方TOEFL词汇

## 3420. spun

**拉成丝的**

:::tip{title=🤩短语}

- spun yarn （细纱，纺成纱）

- spun silk （n. 绢丝）

- spun out （使勉强够用一段时间）

- core spun yarn （包芯线）

- ring spun （环锭纺）

:::

:::note{title=🎤例句}

- As the nebula collapsed because of its gravity, it spun faster and flattened into a disk. （随着由于重力引起的星云坍缩，它旋转得越来越快，并变成了盘状。）

:::

:::warning{title=🤔同义词}

- spined （纺（spin的过去分词）；旋转）

:::
