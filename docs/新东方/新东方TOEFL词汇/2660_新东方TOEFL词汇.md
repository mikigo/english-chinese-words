# 2660_新东方TOEFL词汇

## 2660. extrapolate

**外推； 推断， 推知**

:::note{title=🎤例句}

- Extrapolating from his latest findings, he reckons about 80% of these deaths might be attributed to smoking. （从他最近的发现推断，他估计大约80%的这类死亡可能归因于吸烟。）

:::

:::warning{title=🤔同义词}

- understand, conclude （[数]外推；推断）

:::
