# 480_新东方GRE词汇

## 480. brew

**酿酒； 沏， 煮； 酝酿， 即将发生**

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- impend （酿酒；被冲泡；即将发生）

- beer, texture （啤酒；质地）

:::
