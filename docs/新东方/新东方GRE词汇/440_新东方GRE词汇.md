**车床**

- nc lathe （数控车床）

- vertical lathe （[机]立式车床（等于ertical boring mill））

- lathe tool （[机]车刀）

- horizontal lathe （卧式车床）

- lathe bed （车床床身）

- precision lathe （精密车床）

- engine lathe （普通车床）

- lathe work （车工工作；（钞票纸或证券纸的）彩纹；车削加工）

:::

- tool, turning machine （[机]车床；机床）

:::
