## 248. thirst

**渴， 口渴；渴望， 热望**

- die of thirst （口渴死）

- thirst for revenge （渴望复仇）

:::

:::note{title=🎤例句}

- Maggie woke up with a raging thirst (= an extremely strong thirst ) . （玛吉醒来时感到口干舌燥。）

:::

- aspiration, longing for （渴望；口渴；热望）

- rare, aspire （渴望；口渴）

:::
