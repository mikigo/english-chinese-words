## 840. swallow

**吞咽；忍受**

**燕子**

:::tip{title=🤩短语}

- swallow up （淹没；吞下去；耗尽）

:::

:::note{title=🎤例句}

:::

:::warning{title=🤔同义词}

- stomach, go, stand, abide, tough （忍受；吞没）

- get sth down, get down （吞下；咽下）

:::
