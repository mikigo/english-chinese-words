## 3460. tighten

**变紧； 使更加严格， 加强**

:::tip{title=🤩短语}

- tighten up （加强；使紧密；拉紧；使更牢固）

- tighten one's belt （节约度日；束紧腰带）

:::

:::note{title=🎤例句}

- Tighten the screws firmly. （把螺丝拧紧。）

- I’d put the new tyre on, but I hadn’t tightened up the wheel. （我把新轮胎装上了，但没有上紧轮子。）

:::

:::warning{title=🤔同义词}

- straiten （绷紧；变紧）

:::
