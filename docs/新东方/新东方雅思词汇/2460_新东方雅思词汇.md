:::tip{title=🤩短语}

- transform into （转变成）

- discrete cosine transform （离散余弦变换）

- laplace transform （拉普拉斯变换）

- discrete fourier transform （离散傅里叶变换）

- integral transform （积分变换；积分转换）

- inverse transform （逆变换；反转换）

- transform coding （变换编码；转换编码）
