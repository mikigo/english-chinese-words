- thin layer （薄层；薄膜层）

- soil layer （土层；土壤层次）

- oil layer （油层；含油地层；含油层；油膜）

- outer layer （外层）

- physical layer （物理层）

- protective layer （保护层）

- upper layer （上层）

- bottom layer （底层）

- inner layer （内层）

:::
