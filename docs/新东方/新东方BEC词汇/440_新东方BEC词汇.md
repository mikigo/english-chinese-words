## 440. attach

**系， 贴， 连接； 附加； 使依恋， 使喜爱； 认为有； 使附属**

:::tip{title=🤩短语}

- attached please find （附上…请查收[书信用语]）

- attach file （附件）

:::

:::note{title=🎤例句}

- It’s easy to become attached to the children you work with. （你很容易就会喜欢上工作中接触到的孩子。）

:::

:::warning{title=🤔同义词}

- stick on, piece on （使依附；贴上；系上；使依恋）

- to accompany, be with （附加；附属；伴随）

:::
