# 1240_新东方BEC词汇

## 1240. antedate

**在上写上比实际日期早的日期； 倒填日期； 先于； 使提前发生**

:::note{title=🎤例句}

- The economic troubles antedate the current administration. （这些经济问题早在现任政府就职之前就已出现。）

:::

**应用， 适用； 涂， 敷， 施**
