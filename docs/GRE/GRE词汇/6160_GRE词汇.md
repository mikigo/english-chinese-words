# 6160_GRE词汇

## 6160. slew

`slu:`  **回转**

:::tip{title=🤩短语}

- a slew of （大量的）

- slew rate （转换速率，转换速度）

:::

:::warning{title=🤔同义词}

- turning, circumgyration （回转；沼地；极多）

- swing, turn towards （扭转；侧滑；转向；猛拐）

- turn, spin （使扭转；使旋转）

- martyred （杀害（slay的过去式））

:::
