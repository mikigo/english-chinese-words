# 2220_GRE词汇

## 2220. physique

`fi'zi:k`  **(男子的)体格, 体形**

:::note{title=🎤例句}

- She didn’t have the physique to be a dancer. （她没有当舞蹈演员的体形。）

- He had good health and a strong physique. （他身体健康，体格健壮。）

:::

:::warning{title=🤔同义词}

- figure, build （体格，体形）

:::
