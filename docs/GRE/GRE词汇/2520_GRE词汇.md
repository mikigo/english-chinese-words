## 2520. oracle

`'ɔrəkl, 'ɔ:-`  **[宗](古希腊)神谕, 预言, 神谕处, 神使, 哲人, 圣贤美国ORACLE公司, 主要生产数据库产品, 也是主要的网络计算机的倡导者**

:::tip{title=🤩短语}

- delphic oracle （德尔斐神谕）

:::

:::warning{title=🤔同义词}

- prediction, message （神谕；预言；神谕处；圣人）

:::
