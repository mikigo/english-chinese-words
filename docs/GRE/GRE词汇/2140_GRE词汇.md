# 2140_GRE词汇

## 2140. schlock

`ʃlɔk`  **次品，伪劣品，伪劣货**

:::note{title=🎤例句}

- The gift store sells both tasteful gifts and cheap schlock. （这家礼品店既出售高档礼品，又经销劣质便宜货。）

:::

:::warning{title=🤔同义词}

- inferior, shlock （伪劣品；次品）

- mean, base, budget （低劣的；廉价的（等于shlock））

:::
