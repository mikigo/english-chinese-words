# 6980_GRE词汇

## 6980. ascertain

`,æsə'tein`  **确定, 探知**

:::note{title=🎤例句}

- A postmortem was ordered to try to ascertain the cause of death. （下令验尸以查明死因。）

:::

:::warning{title=🤔同义词}

- confirm, identify, assure oneself （确定；查明；探知）

:::
