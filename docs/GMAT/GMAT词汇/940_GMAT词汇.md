# 940_GMAT词汇

## 940. singularly

`'siŋgjuləli`  **异常地；非常地；令人无法理解地**

:::note{title=🎤例句}

- a singularly foolish plan （极为愚蠢的计划）

- He has singularly failed to live up to his promises. （他显然没有履行自己的诺言。）

:::

:::warning{title=🤔同义词}

- considerably, exceptionally, remarkably （异常地；非常地；令人无法理解地）

:::
