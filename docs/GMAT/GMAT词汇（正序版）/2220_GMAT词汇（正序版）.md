# 2220_GMAT词汇（正序版）

## 2220. provided

`prə'vaidid`  **假如；倘若**

`prə'vaidid`  **提供；给予（provide的过去式）**

:::tip{title=🤩短语}

- provided by （具有；由…提供）

- provided with （拥有，装备有…）

:::

:::note{title=🎤例句}

- That can only be provided by the US. （那角色只有美国才能提供”。）

- The local government provided special buses for the guests. （地方政府为宾客提供了专车。）

:::

:::warning{title=🤔同义词}

- if, supposing （假如；倘若）

- gave, supplied （提供；给予（provide的过去式））

:::
